## Транспорт

- `POST http://127.0.0.1:<порт>/rpc`, JSON-RPC 2.0, один запрос — один ответ;
  ответ `application/json; charset=utf-8`, HTTP 200 для любого JSON-RPC-ответа.
- Слушается только `QHostAddress::LocalHost`. Другие пути и методы HTTP — 404.
- `X-Grams-Sim-Token` проверяется до разбора запроса, если токен задан.

## Коды Issue (`sim.validate`, `INVALID_PROFILE`)

| Ошибки | Когда |
|---|---|
| `SCHEMA` | не объект / неверная `schema` / нет `name` / неверный тип поля |
| `EMPTY_PHASES` | `phases` пуст |
| `BAD_PHASE_ID`, `DUPLICATE_PHASE_ID` | id не `[a-z0-9_]+` / повтор |
| `BAD_KIND`, `BAD_ZONE`, `H2_ZONE` | неизвестные kind/zone; `h2Inlet` не в `chamber` |
| `UNKNOWN_CHANNEL`, `DUPLICATE_TRACK` | канала нет в каталоге / второй трек того же канала в фазе |
| `UNKNOWN_VALVE`, `UNKNOWN_TARGET` | клапана или фазы `to` нет |
| `FIRST_POINT_NOT_ZERO`, `NON_MONOTONIC_TIME` | первая точка не `t = 0` / `t` не строго растёт |
| `CURRENT_NOT_FIRST` | `"current"` не в первой точке |
| `LOG_NONPOSITIVE`, `EXP_NO_TAU` | `log` с `v ≤ 0` / `exp` без `tau > 0` |

| Предупреждения | Когда |
|---|---|
| `PRESSURE_RISE_IN_PUMPING` | в `pumping` давление канала **участка фазы** растёт |
| `PRESSURE_FALL_IN_INLET` | в `gasInlet`/`h2Inlet` давление канала участка фазы падает |
| `TIMEOUT_WITHOUT_DURATION` | переход `timeout` у фазы без `durationSec` |
| `VALUE_OUT_OF_RANGE` | значение вне диапазона канала (будет ограничено) |
| `UNREACHABLE_PHASE` | фаза недостижима из первой по переходам |

## Вопросы к контракту и открытые вопросы

Ниже для каждого вопроса указано, как он решён в GRAMs сейчас (**по умолчанию**).
Контракт при этом не менялся.

1. **Приёмка №1 противоречит принципу 1.3.1.** Без `--sim` порт не открыт,
   поэтому viewer увидит «GRAMs недоступен», а не `simEnabled:false`.
   По умолчанию: соблюдается 1.3.1, `simEnabled` в ответе всегда `true`.
2. **id клапанов.** По умолчанию: К-номер латиницей (`K176`), код — в `label`.
3. **Виртуальные ёмкости** (C1–C3, B, D1, E, D2, F) — производные квартилей, в
   каталоге их нет. Нужна ли в v1.1 подсказка `Channel.feeds`?
4. **Участок `supply`** своих датчиков давления не имеет: линию подачи меряют
   DD311/DD312. По умолчанию в `supply` отнесены термопары DT350, DT351, DT357.
5. **Коды Issue** — список выше; его нужно сверить с viewer.
   `DUPLICATE_TRACK`, `TIMEOUT_WITHOUT_DURATION`, `VALUE_OUT_OF_RANGE`,
   `UNREACHABLE_PHASE` добавлены сверх перечисленного в контракте.
6. **Проверки роста и падения** применяются только к каналам давления и вакуума
   **участка фазы**: при `h2Inlet` резервуар законно падает. Отрезки от
   `"current"` пропускаются.
7. **`interp` не задан** — умолчание по виду фазы: `static` → step, `pumping` →
   log для каналов с `scale: log`, иначе linear, для напусков — linear.
8. **`startPhaseId` не задан** → `phases[0]`.
9. **`sim.goto` на паузе** переходит в фазу (elapsed = 0) и оставляет прогон на
   паузе. **`sim.goto` в `fault`** отвечает `{ok:true}`, но перехода нет.
   `sim.stop` из `fault` ведёт в `idle`; до этого `runId` сохраняется.
10. **`lastError`** — строка или `null`; очищается при новом `sim.run`.
11. **`channels` в `status`** — заданные значения (после шума и ограничения
    диапазоном), а не прочитанные обратно после калибровки (разница ~1e-9).
12. **Качество вакуумметров** профилем не задаётся. Выше 761 Торр автоматически
    `OverRange`; явное `quality` (NoResponse/Stale) предлагается для v1.1 — оно
    нужно, чтобы проигрывать ожидания over range на 300/350 с.
13. **`regime.step`** — строка `VacuumRunMonitor.currentLabel` или `null`, если
    шаг неизвестен; `regime` = `null`, пока `RegimeTaskTree` не выполняет режим.
14. **Ошибки без данных** не содержат поля `error.data`.

Открытые вопросы вне контракта:

- CSV «Напуска» и «Натекания» и лог приложения в демо-режиме не отделены от
  экспериментальных: пути зашиты в квартилях.
- «Появление железа» во время работы не отслеживается: разрешение проверяется
  при запуске.
- Устаревший `InletAction` читает давление из пула `QtConcurrent`; на демо-данных
  такие вызовы пропускаются с предупреждением.
